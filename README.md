# SOUL
SOUL (Simple Optimized Universal Language) is my attempt at making a language that would be genuinely enjoyable to use.

## What is this?
I realized recently that the fast performing languages like C++ or Rust all have downsides that make them at least
slightly unpleasant to code in. Obviously, I can't satisfy everyone's coding style, but what I can do is make one
that I could enjoy coding it. It will probably never be mainstream, but in the small chance that it does, I hope 
that SOUL would make you love coding all over again.

## Planning
Here are my plans for SOUL

- Minimal yet readable syntax
- Compiles machine code targetting a VM
- Also compiles targetting native machine code
